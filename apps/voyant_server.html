Application Description

Voyant Server version 6.18 by Voyant Consortium is a specialized software application designed to facilitate text analysis and visualization for large-scale datasets. It provides researchers and analysts with tools for processing, exploring, and interpreting textual data through interactive visualizations and statistical summaries. The application is primarily used by academic researchers, digital humanities scholars, and data professionals who require advanced text mining capabilities.

The software supports a range of analytical functions, including frequency analysis, collocation detection, and trend identification across corpora. Its server-based architecture enables collaborative workflows, allowing multiple users to access and analyze shared datasets simultaneously. Voyant Server is particularly suited for institutions and research teams working with extensive textual collections, such as libraries, universities, and corporate research departments.

Purpose: Creates the necessary directory structure for the application installation. This ensures all required folders exist before files are copied.

Install OpenJDK11U-jdk_x64_windows_hotspot_11.0.27_6 using MSI package
Start-ADTMsiProcess -Action Install -FilePath "OpenJDK11U-jdk_x64_windows_hotspot_11.0.27_6.msi" -ArgumentList "/QN ALLUSERS=1"

Purpose: Performs the primary installation of the application using the MSI installer. The quiet mode ensures a completely silent installation with no user interface displayed.

Install Phase

Main application installation

Extract VoyantServer.zip archive
Expand-Archive -Path ".\Files\VoyantServer.zip" -DestinationPath "C:\Program Files\Voyant Server" -Force -ErrorAction Stop

Purpose: Extracts the application files from a compressed archive to the installation directory.

Configuration and setup after installation
