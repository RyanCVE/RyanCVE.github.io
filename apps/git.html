Application Description

Git is a distributed version control system designed to track changes in source code during software development. It enables multiple developers to collaborate on projects by managing revisions, branching, and merging code efficiently. The software is primarily used by software engineers, DevOps professionals, and development teams working on projects of varying scales, from small scripts to large enterprise applications.

Version 2.49.0, maintained by Johannes Schindelin, includes performance optimizations and bug fixes to enhance stability and usability. Git supports non-linear development workflows, allowing users to work offline and synchronize changes later. Researchers, open-source contributors, and IT professionals rely on Git for its robust version control capabilities and seamless integration with modern development tools.

Installation Process

Install Phase

Main application installation

Execute Git-2.49.0-64-bit installer
Start-ADTProcess -FilePath "Git-2.49.0-64-bit.exe" -ArgumentList "/SP- /VERYSILENT /NORESTART"

Purpose: Executes application-specific configuration tasks as part of the deployment process.

Post-Install Phase

Configuration and setup after installation

Create registry entry for application tracking
Set-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\RM\Git_v2.49.0_x64"

Purpose: Creates a custom registry entry for deployment tracking and management purposes. This allows system administrators to monitor and verify the installation status.

Uninstallation Process

Uninstall Phase

Remove the application from the system

Execute unins000 installer
Start-ADTProcess -FilePath "C:\Program Files\Git\unins000.exe" -ArgumentList "/SILENT" -WindowStyle Minimized -WaitForMsiExec

Purpose: Executes application-specific configuration tasks as part of the deployment process.

Post-Uninstall Phase

Clean up and remove tracking information

Remove registry tracking entry
Remove-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\RM\Git_v2.49.0_x64"

Purpose: Removes the custom registry entry created during installation, ensuring complete cleanup of tracking information.
