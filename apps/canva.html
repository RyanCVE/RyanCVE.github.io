Vendor: Canva | Architecture: x64 | Language: EN | Revision: 01

Application Description

Canva is a cloud-based graphic design platform that enables users to create visual content such as presentations, social media graphics, posters, and marketing materials. The software provides a drag-and-drop interface with pre-designed templates, stock images, and customizable design elements, streamlining the creation of professional-quality visuals. It is primarily used by marketers, educators, small business owners, and non-designers who require an accessible tool for producing visually engaging content without advanced design expertise.

The platform supports collaborative workflows, allowing multiple users to edit and share designs in real time. Canva also includes features for brand consistency, such as custom color palettes and font libraries, making it suitable for teams managing corporate or organizational branding. Its target user base extends to professionals in communications, HR, and academia who need efficient tools for creating polished visual assets.

Installation Process

Install Phase

Main application installation

Copy application files to target location
Copy-ADTFile -Path "$($adtSession.DirFiles)\Canva.lnk" -Destination "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Canva" -Recurse -FileCopyMode Robocopy -ErrorAction Stop

Purpose: Copies necessary application files to their target locations as part of the deployment process.

Post-Install Phase

Configuration and setup after installation

Create registry entry for application tracking
Set-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\Canva_PWA_x64"

Purpose: Creates a custom registry entry for deployment tracking and management purposes. This allows system administrators to monitor and verify the installation status.

Uninstallation Process

Post-Uninstall Phase

Clean up and remove tracking information

Remove registry tracking entry
Remove-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\Canva_PWA_x64"

Purpose: Removes the custom registry entry created during installation, ensuring complete cleanup of tracking information.

Technical Details

  • Deployment Framework: PowerShell Application Deployment Toolkit (PSADT)
  • Supported Operations: Install, Uninstall, Repair
  • Target Platform: Windows (Enterprise deployment via SCCM/MECM)
  • Installation Type: Automated deployment
  • User Interaction: Silent installation supported
