Vendor: Tom Hall | Architecture: x86 | Language: EN | Revision: 01

Application Description

BioEdit is a biological sequence alignment editor designed for Windows systems. It serves as a comprehensive replacement for commonly used DOS sequence alignment editors, providing a rich set of sequence editing, alignment, manipulation, and analysis functions. This application is particularly valuable for researchers and professionals working in bioinformatics, molecular biology, and genetic analysis.

The software offers an intuitive Windows-based interface that simplifies complex biological sequence operations, making it accessible to both novice and experienced users in the field of computational biology.

Installation Process

Pre-Install Phase

Preparation steps before the main installation to ensure system compatibility.

Install Visual C++ Redistributable (x86) as a prerequisite
Start-ADTProcess -FilePath "VC_redistx86.exe" -ArgumentList "/Install /Quiet /Norestart" -WaitForMsiExec -ErrorAction Continue

Purpose: Installs the Microsoft Visual C++ Redistributable package required for BioEdit to function properly. The installation runs silently without user interaction and continues even if errors occur.

Install Phase

Main application installation using the MSI package.

Install the main BioEdit application
Start-ADTMsiProcess -Action Install -FilePath "BioEdit.msi" -ArgumentList "QN"

Purpose: Performs the primary installation of BioEdit using the MSI installer. The "QN" argument ensures a completely quiet installation with no user interface displayed.

Post-Install Phase

Configuration and registry setup after successful installation.

Create registry entry for application tracking
Set-ADTRegistryKey -Key "HKEY_LOCAL_MACHINE\SOFTWARE\InstalledApps\AppPackaging\...\RM\BioEdit_v7.7.1.0_x86"

Purpose: Creates a custom registry entry for deployment tracking and management purposes. This allows system administrators to monitor and verify the installation status.

Uninstallation Process

Uninstall Phase

Remove the BioEdit application from the system.

Uninstall BioEdit using MSI product code
Start-ADTMsiProcess -Action Uninstall -ProductCode "{691DD9D4-9123-4A4B-833E-7C7C93451964}" -ArgumentList "/QN"

Purpose: Removes BioEdit from the system using its unique MSI product code. The silent uninstallation ensures no user prompts are displayed.

Post-Uninstall Phase

Clean up registry entries and remove tracking information.

Remove registry tracking entry
Remove-ADTRegistryKey -Key "HKEY_LOCAL_MACHINE\SOFTWARE\InstalledApps\AppPackaging\...\RM\BioEdit_v7.7.1.0_x86"

Purpose: Removes the custom registry entry created during installation, ensuring complete cleanup of tracking information.
