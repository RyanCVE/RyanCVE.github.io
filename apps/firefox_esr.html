Firefox ESR v128.11.0
Vendor: Mozilla Corporation | Architecture: x64 | Language: EN | Revision: 01

Application Description

Firefox ESR (Extended Support Release) version 128.11.0 is a long-term maintenance version of the Mozilla Firefox web browser designed for enterprise and organizational environments. It provides stable, secure browsing with fewer feature updates, ensuring compatibility with internal systems and reducing the need for frequent adjustments. This version includes critical security patches and performance improvements while maintaining a consistent user experience over an extended support cycle.

The target user base for Firefox ESR consists of IT administrators, educational institutions, and businesses requiring a predictable browser environment for large-scale deployments. It is particularly suited for environments where frequent updates could disrupt workflows or require extensive compatibility testing. Firefox ESR balances security with stability, making it a reliable choice for organizations prioritizing long-term usability over cutting-edge features.

Installation Process

Install Phase

Main application installation

Install Firefox Setup 128.11.0esr using MSI package
Start-ADTMsiProcess -Action Install -FilePath "Firefox Setup 128.11.0esr.msi" -ArgumentList "/QN TASKBAR_SHORTCUT=false DESKTOPSHORTCUT=false PRIVATE_BROWSING_SHORTCUT=false PREVENT_REBOOT_REQUIRED=true"

Purpose: Performs the primary installation of the application using the MSI installer. The quiet mode ensures a completely silent installation with no user interface displayed.

Post-Install Phase

Configuration and setup after installation

Create registry entry for application tracking
Set-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\RM\Firefox_ESR_v128.11.0_x64"

Purpose: Creates a custom registry entry for deployment tracking and management purposes. This allows system administrators to monitor and verify the installation status.

Uninstallation Process

Uninstall Phase

Remove the application from the system

Execute helper installer
Start-ADTProcess -FilePath "C:\Program Files\Mozilla Firefox\uninstall\helper.exe" -ArgumentList "/S" -WaitForMsiExec

Purpose: Executes application-specific configuration tasks as part of the deployment process.

Post-Uninstall Phase

Clean up and remove tracking information

Remove registry tracking entry
Remove-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\RM\Firefox_ESR_v128.11.0_x64"

Purpose: Removes the custom registry entry created during installation, ensuring complete cleanup of tracking information.

Technical Details

  • Deployment Framework: PowerShell Application Deployment Toolkit (PSADT)
  • Supported Operations: Install, Uninstall, Repair
  • Target Platform: Windows (Enterprise deployment via SCCM/MECM)
  • Installation Type: Automated deployment
  • User Interaction: Silent installation supported
