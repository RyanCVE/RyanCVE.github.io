Application Description

OpenShot is a cross-platform video editing application designed for creating and modifying digital video content. It provides a user-friendly interface with support for multiple tracks, transitions, keyframe animations, and a wide range of video and audio formats. The software is primarily used by content creators, educators, and small businesses for producing professional-quality videos without requiring advanced technical expertise.

Version 3.3.0 introduces enhanced stability, improved performance, and additional effects libraries for greater creative flexibility. OpenShot caters to users who need a reliable, open-source solution for tasks such as video trimming, compositing, and audio synchronization. Its intuitive workflow makes it suitable for both beginners and intermediate editors seeking a balance between functionality and ease of use.

Installation Process

Install Phase

Main application installation

Execute OpenShot-v3.3.0-x86_64 installer
Start-ADTProcess -FilePath "OpenShot-v3.3.0-x86_64.exe" -ArgumentList "/SP- /VERYSILENT /NORESTART /ALLUSERS" -WaitForMsiExec

Purpose: Executes application-specific configuration tasks as part of the deployment process.

Post-Install Phase

Configuration and setup after installation

Create registry entry for application tracking
Set-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\RM\OpenShot_v3.3.0_x64"

Purpose: Creates a custom registry entry for deployment tracking and management purposes. This allows system administrators to monitor and verify the installation status.

Uninstallation Process

Uninstall Phase

Remove the application from the system

Execute unins000 installer
Start-ADTProcess -FilePath "C:\Program Files\OpenShot Video Editor\unins000.exe" -ArgumentList "/SILENT" -WindowStyle Minimized -WaitForMsiExec

Purpose: Executes application-specific configuration tasks as part of the deployment process.

Post-Uninstall Phase

Clean up and remove tracking information

Remove registry tracking entry
Remove-ADTRegistryKey -Key "HKLM:\SOFTWARE\...\Arts\RM\OpenShot_v3.3.0_x64"

Purpose: Removes the custom registry entry created during installation, ensuring complete cleanup of tracking information.
